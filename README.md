日志审计要求能自证某条记录没被改过，接上默克尔树之后，包含证明和一致性证明都能被伪造：叶子哈希与内部节点哈希共用同一前缀，内部节点可被当作叶子做第二原像；建树时左右子交换后父哈希不变，兄弟顺序没有绑定；奇数层把最后一个节点直接复制成对，重复叶攻击使证明可以重复伪造；空树根返回空字节串，与单叶树无法区分；包含证明不带树大小，不同大小的树可以交叉验证通过；证明索引按从左到右的位序解释而不是从右到左取位，路径方向错误；一致性证明只比较根相等，不验证旧根是新树前缀；建树缓存上一次的层表，第二棵树沿用第一棵的中间层；验证函数遇到长度不符直接抛异常而不是返回 False，调用方无法统一处理；域分离常量在派生时被截断到 16 字节，前缀区分失效。mtree/_impl.py 是核心，tests/test_merkle.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。
